Hubungkan Firebase & Siap Publish

Sinkronisasi real-time antar perangkat Guru & Siswa via Cloud Firestore.

Saat ini berjalan di Mode Lokal. Tempel konfigurasi Firebase di bawah agar data kuis & skor tersinkronisasi online.
  1. Buka Firebase Console, buat project baru (gratis), lalu aktifkan Firestore Database (pilih Test mode saat mulai).
  2. Masuk ke Project Settings → Your apps → Web (</>), lalu salin objek firebaseConfig.
  3. Tempel isi firebaseConfig ke kotak di bawah lalu klik Simpan & Hubungkan.
  4. Klik Unduh index.html Siap Publish, lalu upload ke Netlify Drop atau GitHub Pages.
